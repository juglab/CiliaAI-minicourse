# Put your denoised images here

Name each file `<who>_<what>.tif`, for example `anna-ben_part1-chatgpt.tif` or `anna-ben_part2-n2v-colab.tif`. Then run, from the top folder of the course material:

```bash
uv run denoising/benchmark/benchmark.py
```

Everything in this folder except this README is ignored by git, so your results stay on your laptop. See [`../README.md`](../README.md) for details.
